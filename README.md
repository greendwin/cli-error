# app-error

Application error handling and reporting utilities.

## Getting started

### Prerequisites

- Python 3.12+
- [uv](https://docs.astral.sh/uv/)

### Setup

```bash
uv sync
```

### Usage

```python
from app_error import greet

print(greet("World"))  # Hello, World!
```

### Testing

```bash
uv run tox
```
